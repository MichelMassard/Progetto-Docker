# Chat con traduzione automatica

Una piccola chat web: ognuno scrive nella propria lingua e chi legge sceglie in che lingua vedere i messaggi (italiano, inglese, tedesco o francese). L'applicazione è fatta con PHP, MariaDB e LibreTranslate, e gira tutta in Docker.

Progetto del laboratorio Docker. Le scelte fatte e i loro motivi sono spiegati nel diario (`Diario-Docker.docx`).
